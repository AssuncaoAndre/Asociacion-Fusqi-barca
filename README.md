# Asociación Fusqi — possession labels for More than a Hack 2027

From the provided match bundle (tactical video + ATD tracking + smart tagging + homography) to a
per-frame possession file (`H` / `A` / `D` / `X`, one row per video frame, 199,319 rows), ranked on
**spellF1** with **macroF1** as the tie-break.

The pipeline is a **hybrid**: hand-written rules (`solution/model.py`, v12) decide in play vs dead,
and a small trained model (`ml/`, gradient boosting + Viterbi, trained only on other matches —
DFL open data and Metrica sample games) decides which team has the ball. See
**`Asociación Fusqi.md`** (the technical document) for the approach, the training data, the
possession rules, the limitations and the reproduction steps.

## Install

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt -r ml/requirements.txt   # Python 3.11+; pinned versions
```

## Data

The match data is gated and is **not** in this repository. Download the bundle (see `DATA.md`) and
either place it in `./data` or point `MTAH_DATA_DIR` at the folder that contains `tactical/`:

```bash
export MTAH_DATA_DIR=/path/to/the/data/bundle
```

## Run — regenerate the submission file

```bash
python ml/predict.py "Asociación Fusqi.csv"
```

This writes the submission file (`Asociación Fusqi.csv`, the exact file that was submitted), in ~1
minute, using the trained model committed in `ml/artifacts/`. The output is deterministic: the same
data bundle plus the pinned dependencies reproduce the file byte for byte. The first run parses the
raw ATD (~15 s) and caches it under `$MTAH_CACHE_DIR` (default `/tmp/mtah_cache`).

## Self-check

```bash
python evaluation/validate_submission.py "Asociación Fusqi.csv"   # the format checks the scorer runs
python solution/score.py "Asociación Fusqi.csv"                   # score on the public 5-min GT
python solution/sanity.py "Asociación Fusqi.csv"                  # whole-match label shares, D runs
```

## Retrain the model (optional)

The committed `ml/artifacts/` is what produced the CSV. To retrain from scratch, download the
other-matches data into `other-games/` (commands in `validation/README.md`) and run:

```bash
python ml/train.py        # ~20 min -> ml/artifacts/model.joblib + config.json
```

If you retrain, regenerate the CSV with `python ml/predict.py "Asociación Fusqi.csv"` and commit the
new artifacts together with the new CSV.

## Layout

```
solution/model.py       the rules model (v12): tracking clean-up -> alive/dead machine -> sticky possession
solution/load_data.py   ATD parsing (cached), team metadata, public GT loader
solution/features.py    smart-tagging features (parsed, deliberately unused — see the doc)
solution/score.py       public-window scoring detail
solution/sanity.py      whole-match sanity report
ml/common.py            features, Viterbi decoder, hybrid constraint, scoring
ml/train.py             training: features for the 9 other matches, held-out evaluation, final model
ml/predict.py           submission: saved model + rules model -> the CSV
ml/artifacts/           the trained model + its settings (committed on purpose)
validation/             DFL bench + Metrica loader (training data loaders, download commands)
evaluation/             the organisers' public scoring/validation scripts + public 5-min GT
games.py, DATA.md       challenge files (data locations, per-game constants)
Asociación Fusqi.csv    the submission file (regenerated by the command above)
Asociación Fusqi.md     the technical document
```
